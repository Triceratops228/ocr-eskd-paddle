# OCR ЕСКД спецификаций

Скрипт `ocr_eskd_paddle_progress.py` рекурсивно обрабатывает PDF-файлы со спецификациями ЕСКД, распознаёт детали и строит иерархию сборок по структуре папок.

## Возможности

- выбор корневой папки через диалог Windows или аргумент командной строки;
- каждая папка считается сборкой, вложенные папки — дочерними сборками;
- обработка PDF-файлов во всех вложенных папках;
- OCR диапазона таблицы: строки 2–27 и столбцы 6–8;
- распознавание раздела «Детали»;
- объединение многострочных наименований деталей;
- связывание дочерней сборки с деталью родительской сборки по децимальному обозначению или названию;
- экспорт в `eskd_structure.json` и `eskd_details.xlsx`.

## Установка

Рекомендуется использовать Python 3.10 или совместимую версию:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Для работы PaddleOCR на CPU скрипт автоматически переключается на CPU, если GPU недоступен.

## Запуск

С диалогом выбора папки:

```powershell
python ocr_eskd_paddle_progress.py
```

С путём к корневой папке:

```powershell
python ocr_eskd_paddle_progress.py "C:\path\to\specifications"
```

Результаты сохраняются в подпапку `eskd_paddle_result` выбранной корневой папки. Входные PDF и сгенерированные результаты не включаются в Git-репозиторий.
